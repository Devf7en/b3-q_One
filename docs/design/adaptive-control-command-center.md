# Adaptive Control Command Center

All views share one canonical resource registry, tenant context, permissions, commands and evidence. Views are presentation projections, not separate systems. Light/dark theme is independent of view.

## Views
- Mission Control: topology, telemetry, incidents and operations.
- Business Workspace: customers, projects, hosting, domains, subscriptions and outcomes.
- Intelligence Workspace: conversational intent, plan simulation, approval and evidence.
- Developer Studio: repositories, pipelines, containers, logs and releases.
- Spatial Infrastructure: dependency graph, regions, networks and resources.
- Executive Overview: cost, reliability, risk and business outcomes.
- Custom Canvas: dockable, resizable panels, saved layouts and presets.

## Shared shell
One-row navigation, consistent logo dimensions, persistent AI command bar, tenant/project selector, view switcher, theme switcher, notifications and evidence freshness. Progressive disclosure, responsive layout, keyboard navigation and accessible contrast. Preserve all 16 environment contracts. No view grants additional permissions.

## Dual surface
Control Command Center permits server-authorized operations. Project Observatory shares visual tokens and read-only projections; no mutation controls. Reciprocal navigation and common resource identifiers.

## Acceptance
Switching views preserves selected tenant/project/resource; layout persistence is tenant/user scoped; every operational observation has provenance and freshness; demonstration values are explicitly labeled; all mutation paths enforce server-side authorization. Visual inspiration is conceptual, not a claim of implemented UI.
