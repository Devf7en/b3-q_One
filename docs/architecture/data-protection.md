# One Resilience — 13C.4

Local backup: from repository root with the development stack running, execute bash scripts/backup-postgres.sh /absolute/private/backup-directory. The script creates a custom-format logical dump, catalog and SHA-256 manifest in a private staging directory before publishing the backup directory. It does not encrypt the dump or verify a restore. Use encrypted storage outside the repository; never upload database dumps to GitHub. Recovery CI restores the migrated schema into a separate disposable database and reruns SQL acceptance. This is not a production recovery or populated-data fidelity test. Pending: encrypted offsite copies, retention, scheduling, migration history and checksums, populated fixture restore, measured RPO/RTO, independent manifest anchoring and operational integration with W17. No automatic destructive restore or deletion.
