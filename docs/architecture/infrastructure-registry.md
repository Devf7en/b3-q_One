# Authoritative infrastructure registry

Migration 007 extends the existing resource model with hosts, collector identities and explicit assignments. Host and collector registrations default to disabled. A host/kind/external reference can belong to only one canonical resource; the composite foreign key prevents assigning a resource to a different tenant or project. Assignment rows enforce forced tenant RLS. Host and collector metadata remain administrative only; no service or collector role receives direct table privileges. Registration is not proof of connectivity or authentication. No public registration endpoint exists. Future ingestion must verify collector credentials, enabled host and collector state, assignment lifecycle, resource kind consistency, observation provenance and replay controls in a trusted transaction. Docker volume names can be reused; reassignment and lifecycle verification are required before accepting observations in production.
