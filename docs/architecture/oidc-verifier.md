# One::Identity — access-token verifier

Server-only JOSE adapter uses explicitly configured HTTPS issuer and JWKS URL, RS256, issuer/audience checks, required claims, RFC 9068 at+jwt type and 15-minute maximum token age. Provider configuration must be trusted, never derived from token claims. This deliberately narrow profile may require provider-specific configuration; compatibility with Auth0, Keycloak or Entra is not yet verified. Existing identity boundary must resolve authoritative membership after verification. CI installs pinned JOSE for initial configuration and malformed-token tests. Positive signed-token and key rotation acceptance, dependency lockfile, database identity lookup, provider integration, browser PKCE/session and revocation remain outstanding. No credentials or live identity provider are configured.
