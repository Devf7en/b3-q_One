# One::Orchestration — 13C.6

Job lifecycle foundation is a pure non-executable state machine. Draft → review → approved/rejected; approved → cancelled. Approval must come from an authoritative server-side ledger; shape validation is not authentication. Revision checks require atomic persistence to prevent races. Idempotency keys require a tenant-scoped unique database constraint; not yet enforced. Redis is a future coordination/cache adapter, never the authority for approval or audit. n8n is a workflow adapter, not an authorization engine. Future dispatch requires transactional outbox, verified approval, execution grants, bounded retries, reconciliation, secret references and evidence. No Redis or n8n deployment or external calls in this increment. Preserve existing ecosystem n8n installations.
