# One Identity — 13B.3

Server-only dependency-injected identity boundary. A future standards-compliant OIDC access-token verifier must validate signatures, algorithms, trusted keys, issuer, audience, expiry and applicable token type before returning claims. The boundary additionally checks issuer, audience, subject and expiry and resolves authoritative tenant membership. Never accept browser roles or unsigned claims. Tests use fixtures, not real tokens. No identity provider, login route, session store or credentials are configured. Next: vetted OIDC library, authorization code with PKCE, state/nonce, secure HttpOnly cookies, CSRF protection, session rotation/revocation, membership database adapter and real integration tests. Do not expose this module via static Pages. Execution remains disabled.
