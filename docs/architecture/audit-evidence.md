# One Audit and One Evidence — 13B.5

Server-only event envelope records trusted actor, tenant, action, correlation, outcome, optional plan digest, UTC timestamp, sequence and predecessor hash. No arbitrary details or credentials in the envelope. Hash chain verification requires an independently trusted head; hashes alone cannot prevent rewriting an entire chain. Serialize appends per tenant in a database transaction, bind plan/approval writes and audit records atomically, persist the envelope in audit_events.details, and externally anchor heads before claiming tamper resistance. Denied requests need a separate safe logging path. Migration 003 adds row mutation guards, not protection against privileged DDL or TRUNCATE. Evidence freshness is evaluated independently from authenticity; source labels and timestamps alone never establish verified live data. Enterprise Observability adapter, trusted collection, database transactions, retention, access grants and real PostgreSQL acceptance remain pending. Observatory read-only.
