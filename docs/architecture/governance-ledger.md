# One Governance Ledger — 13B.4

Server-only plan envelope uses versioned sorted-key JSON encoding and SHA-256 over tenant, project, plan ID, version, creator and manifest. This is an internal encoding, not a claim of RFC 8785 compliance. Approval requires trusted principal, exact reviewed digest, matching tenant, independent approver and Control Center surface. The returned record is not a signed authorization or execution grant. Persist only through a trusted transactional service; retrieve authoritative plans rather than accepting client-supplied envelopes. Migration 002 rejects row updates/deletes of plans and approvals; restricted database roles must also deny TRUNCATE, DDL and trigger bypass. Database migration execution, concurrency, version allocation, revocation, evidence freshness and transactional audit remain pending. No live execution.
