# One::Provider — Docker inventory

Host-side collector invokes only fixed Docker CLI list commands with no shell, user-supplied arguments or mutation operations. Output is bounded and projected onto explicit fields; raw labels, commands, mounts and diagnostics are excluded. Docker CLI context and host permissions must be controlled by the trusted collector operator. Docker access itself is privileged; never mount the socket into the web app. Inventory is host-wide and may contain sensitive names; do not expose it to tenants until resource ownership mapping and evidence ingestion are implemented. Live means successful observation by this collector, not production connectivity. Failed collection reports unavailable, not an empty healthy host. CI exercises a disposable runner Docker daemon; local Mac and production hosts are not connected. Health inspection, utilization, topology mapping and authenticated evidence delivery remain pending.
