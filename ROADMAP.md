# Roadmap

- Phase 00: constitution, environment registry, architecture, executable simulation, CI and dual-surface design.
- Phase 01: identity, tenancy, provider discovery, VPS/DNS/SSL lifecycle.
- Phase 02: GitHub deployments, containers and templates.
- Phase 03: governed AI planning and operations.
- Phase 04: observability, backup verification, recovery and digital twin.
- Phase 05: billing, customer portal, marketplace and launch gates.
- Phase 06: policy-bounded autonomous operations.

All phases require evidence-backed acceptance. No production deployment without authorization.
